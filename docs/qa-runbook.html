BharatTax QA Runbook

A step-by-step manual test procedure for every feature — with exact inputs and the figures they must produce. Run it end to end for a release, or a single section after a targeted change.

Living document
Scope · Officer & practitioner platform
Environment · bharattax.wenvia.global
Version · v1 · covers PRs #47–#77

How to use this runbook

  1. Pick the environment (staging or prod) and note it on the sign-off.
  2. Work top-to-bottom, or jump to a section after a targeted change.
  3. For each case, follow the steps with the exact test data given, then compare against Expected.
  4. Mark the result. A FAIL or BLOCKER gets a note + screenshot and a ticket.
  5. Regression shortcut: §C and §D are fully deterministic — re-run just those two after any deploy to catch statutory-math regressions to the rupee.

Result legend

PASS Matches expected exactly.
MINOR Works; cosmetic / copy nit.
FAIL Wrong output or broken flow.
BLOCKER Wrong legal figure, data leak, or crash.

A

Onboarding & access

Registration is admin-approved; a seat is leased on login. The first-run prompt tailors the workspace to the officer's function.

IDStepsTest dataExpected resultResult
A1 Register a new account, then have an admin approve it, then log in. Email + password; admin → Users → Approve. New account lands as pending and cannot log in; after approval, login succeeds and lands on Chat.
A2 Log in as a fresh non-admin with no function set. — “What do you mainly work on?” prompt appears once, with the 9 functions, I work across several…, Show everything and Skip for now. After any choice it does not reappear.
A3 Open the app in more sessions than the wing seat limit. Wing seat_limit = N; open N+1 sessions. The N+1th is refused a seat; releasing one frees it. Deactivating a licence signs the user out within ~60s.
A4 Test field validation on registration / matter / profile forms. PAN AAAPL1234C vs abc; AY 2023-24 vs 2023; a bad email / mobile. Valid values accepted; invalid ones are rejected inline with a clear message. PAN uppercases.
B

Workspace profile & tailoring

One function reshapes the whole desk — dashboard, sidebar, calculators and templates — without hiding anything. Test as an Assessing Officer unless noted.

IDStepsTest dataExpected resultResult
B1 Profile → Primary function. Set each mode and save. Single (Assessing Officer); Custom → tick Recovery + TP; Show everything; Not set. Saves and persists across reload. Custom reveals the wing multi-select and requires ≥1 pick. “Not set” re-enables the first-run prompt next session.
B2 Admin → User Management → edit a non-admin user → Primary function. Set to TPO; save; re-open the user. Selector offers Not set / Show everything / 9 functions; the choice saves and shows on re-open. The user’s desk reflects it on next load.
B3 Inspect the sidebar with the AO profile; then collapse it. — Your workspace = Dashboard · Chat · Calendar · Assessments · Calculators · Templates · Rulings · Drafts. All tools (collapsible) holds the rest. Collapsed rail shows every icon.
B4 Open the Dashboard with the AO profile. — Chips = Mine · All · AO only — no DRP/TP/Investigation/etc. Tiles reflect the current filter. “Mine” is default; if no AO-tagged matters exist it opens on “All”. A manual Refresh keeps your chosen chip.
B5 Open Calculators / Templates for several functions. AO, TPO, Investigation, Recovery, TDS. Calculators open on: AO→Interest, TPO→ALP, Investigation→Peak credit, Recovery→Recovery, TDS→TDS. Templates library opens on the matching wing group. All tabs/groups still reachable.

F

Demand tracker

A recovery ledger on the matter, with live Sec. 220(2) interest on the outstanding balance.

IDStepsTest dataExpected resultResult
F1Open a matter → Outstanding demands → Add.Amount ₹10,00,000 · default date 6 months before today · s.156.Row shows outstanding ₹10,00,000 · 220(2) interest ≈ ₹60,000 (6mo @1%) · total ≈ ₹10,60,000. Header shows a “₹… due” badge.
F2Record a part-payment in the Paid box.Paid ₹2,00,000.Outstanding drops to ₹8,00,000; interest recomputes on the reduced balance (≈ ₹48,000 for 6mo).
F3Change status and watch the interest.Set stayed, then reduced, then paid.outstanding & reduced accrue 220(2); stayed & paid accrue ₹0. Fully paid → chip disappears.
F4Return to the Dashboard.—The matter shows a red ₹… due chip (outstanding + interest); it clears when the demand is paid/stayed.
